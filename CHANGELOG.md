# Changelog

## 1.0.0 — 2026-09-16

Initial release.

- `check`: score one or more repositories from daily star history, recent star actors, their public profiles, and watcher ratios.
- `trending`: search, score, and rank repos with a raw and an adjusted rank; writes Markdown.
- `explain`: weights and what each signal means.
- Weekly GitHub Action that commits a fresh leaderboard to `reports/`.
- First report in `reports/2026-09-16.md` and the calibration table in `docs/calibration.md`.
